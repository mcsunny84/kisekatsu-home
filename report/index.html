키세카츠 콘텐츠 리포트는 브랜드 계정의 게시물과 반응을 살펴보고, 다음 콘텐츠를 더 나아지게 만드는 운영 도구입니다.

키세카츠 계정을 관리할 권한이 있는 운영자를 위한 안내입니다. 일반 고객의 식사 예약이나 매장 이용에는 계정 연결이 필요하지 않습니다.

연결 준비 중

TikTok 계정 연결

공식 인증을 통한 계정 연결을 준비하고 있습니다. 현재 이 페이지에서는 로그인이나 TikTok 데이터 수집이 시작되지 않습니다.

연결 기능이 제공되면 TikTok에서 권한을 직접 확인하고 승인할 수 있습니다.

리포트 이용약관 개인정보처리방침

어떤 리포트를 준비하나요?

01 / 게시물 확인

우리가 올린 콘텐츠

연결한 계정의 공개 영상 목록과 게시 시각, 제목, 원본 링크를 정리할 예정입니다.

02 / 반응 살펴보기

숫자와 관찰 시점

제공되는 조회·좋아요·댓글 수·공유 수를 확인합니다. 수집할 수 없는 항목과 실제 0을 구분할 예정입니다.

03 / 다음 콘텐츠

변화를 보고 개선하기

게시 후 반응의 변화를 비교해 운영자가 다음 콘텐츠의 방향을 판단하도록 돕는 것이 목적입니다.

연결 전에 알아두세요

  • 본인이 관리 권한을 가진 계정만 연결할 수 있습니다.
  • 예정된 조회 범위는 계정 식별에 필요한 기본 프로필과 공개 영상 정보·반응 수입니다. 실제 범위는 승인 화면과 정책에서 안내합니다.
  • 댓글 수와 댓글 본문은 다릅니다. 이 연결은 댓글 본문·DM·영상 게시·삭제 권한을 요청하는 용도가 아닙니다.
  • 동의는 선택할 수 있으며, 연결 해제와 데이터 삭제 요청 방법은 개인정보처리방침에서 확인할 수 있습니다.

현재 화면에는 실시간 수치나 연결 완료 상태가 표시되지 않습니다. 실제 제공 항목은 TikTok의 승인 범위와 서비스 제공 상황에 따라 달라질 수 있습니다.
