현재 본 페이지를 통한 TikTok 계정 연결 및 API 데이터 수집은 없습니다. 이 방침은 현재 제공하는 안내 페이지에 적용됩니다. 실제 계정 연결 전에는 수집 항목·목적·구체적인 보유 기간·처리업체 및 국외 이전 여부를 확정해 공개하고, 필요한 동의를 받습니다.

3. TikTok 연결 기능 제공 전에 안내할 내용

연결 기능은 브랜드 콘텐츠의 게시 현황과 반응을 확인하는 리포트를 위해 준비합니다. 최소 조회 범위로 계정 식별 정보·표시 이름·프로필 이미지와 공개 영상의 식별자·제목·게시 시각·링크·조회 수·좋아요 수·댓글 수·공유 수를 검토하고 있습니다.

위 항목은 현재 수집 목록이 아닙니다. 실제 필요한 항목과 승인된 권한만 선택하며, 팔로워 수 등 추가 통계를 처리하게 되는 경우 해당 항목과 권한을 별도로 명시합니다. 댓글 본문·DM·TikTok 비밀번호는 예정된 리포트 수집 범위에 포함하지 않습니다.

연결 제공 시 적용할 보관·삭제 원칙

리포트 원자료의 보유 기간은 수집일로부터 최대 90일로 정합니다. 목적이 달성되어 더 이상 필요하지 않으면 그 전에 파기합니다. 연결 해제 시 추가 수집을 중단하며, 유효한 삭제 요청을 확인한 뒤 지체 없이 처리하고 늦어도 30일 이내에 삭제합니다.

이 원칙은 서비스 제공을 위한 기준이며, 현재 데이터가 수집·보관되고 있다는 의미는 아닙니다. 실제 서버와 백업·전달 사본에서 이 기준을 이행할 수 있는지 확인하기 전에는 계정 연결을 제공하지 않습니다. 법령상 보관 의무가 있는 경우 그 근거·항목·기간은 별도로 고지합니다.

연결을 활성화하기 전에 다음 사항을 실제 서버 처리 방식에 맞춰 이 페이지에 반영합니다.

  • 항목별 처리 목적·법적 근거·수집 방법과 위 원자료 보관 기준의 적용 범위
  • 인증 정보의 보관·갱신·철회 처리와 수집 중단 방법
  • 리포트의 열람 대상 및 전달 방식, 처리위탁·제3자 제공·국외 이전이 있으면 그 상세 사항
  • 위 삭제 기한을 이행하는 절차, 백업·전달 사본의 파기 방법과 법령상 보관 예외

계정 연결에 동의하지 않아도 브랜드 홈페이지 및 매장 이용에는 영향이 없습니다. 연결 기능을 사용하려면 그 기능에 필요한 최소 정보에 관한 안내를 확인하고 동의 절차를 진행해야 합니다.

4. 호스팅과 외부 서비스

본 정적 페이지는 GitHub Pages를 통해 전송됩니다. GitHub는 서비스 제공·보안 등의 목적으로 IP 주소와 요청 관련 정보를 처리할 수 있습니다. 처리 범위·보관·국제적 정보 이전에 관한 사항은 GitHub 개인정보처리방침을 참고해 주세요.

운영자는 현재 본 리포트 페이지를 통해 수집한 TikTok 데이터를 제3자에게 제공하거나 외부 리포트 전송 서비스로 보내지 않습니다. 향후 연결 서버나 리포트 전달 과정에서 위탁·제공·국외 이전이 발생하는 경우 관련 대상, 목적, 항목, 시기·방법, 보유 기간과 필요한 권리 안내를 실제 처리 전에 공개합니다.

TikTok 등 외부 서비스로 이동한 이후 해당 서비스에서 직접 수행하는 개인정보 처리는 그 서비스의 방침에 따릅니다. 운영자가 전달받은 개인정보에 대해서는 본 방침과 관련 법령에 따른 책임을 부담합니다.

5. 열람·정정·삭제·연결 해제

개인정보 처리 여부의 확인, 열람, 정정, 삭제, 처리정지 또는 동의 철회는 아래 문의 창구로 요청할 수 있습니다. 권한 확인에 필요한 최소한의 정보만 확인하며, 비밀번호나 인증 토큰을 보내지 마세요.

현재는 본 페이지에서 연결한 계정이나 저장한 API 데이터가 없습니다. 연결 기능 제공 후에는 TikTok의 앱 접근 권한을 철회하여 이후 접근을 제한할 수 있으며, 운영자에게 연결 해제와 보관 데이터 삭제도 요청할 수 있습니다. 플랫폼 권한 철회만으로 운영자가 이미 보관한 모든 사본이 자동 삭제된다고 안내하지 않습니다.

6. 파기와 보호 조치

현재 본 페이지에서 보관하는 API 데이터는 없습니다. 향후 수집하는 개인정보는 목적 달성, 보유 기간 종료 또는 유효한 삭제 요청에 따라 불필요해지면 지체 없이 파기하는 원칙으로 운영합니다. 법령상 별도 보관이 필요한 경우 해당 근거·항목·기간을 고지하고 분리하여 관리합니다.

실제 연결 기능은 접근 권한 제한과 안전한 인증 정보 보관, 전송 보호, 삭제 절차를 검증한 후 제공합니다. 전자적 자료는 복구하기 어렵도록 삭제합니다. 인증 정보의 유효 기간·폐기 시점과 백업 처리 방식은 연결 전에 확정하여 고지하며, 리포트 원자료의 90일 보유·삭제 요청 확인 후 30일 이내 삭제 기준을 준수하도록 검증합니다.
